# Materna-JO — النسخة الأولية

تطبيق ويب تقدمي (PWA) باللغة العربية لمتابعة الحمل وما بعد الولادة.

## التشغيل
- افتحي `index.html` محلياً للتجربة الأساسية.
- لتثبيت التطبيق والعمل دون اتصال، ارفعي الملفات إلى GitHub Pages أو استضيفيها عبر HTTPS.
- لا يوجد تسجيل دخول أو بريد إلكتروني أو كلمة مرور.
- اختيار «أنا حامل» أو «أنا أم جديدة» يُحفظ على الجهاز.

## البيانات والخصوصية
تُحفظ بيانات الأم في `localStorage` على الجهاز والمتصفح الحالي فقط. حذف بيانات المتصفح أو تغيير الجهاز قد يؤدي إلى فقدانها. لا تُرسل البيانات إلى خادم في هذه النسخة.

## ما تتضمنه النسخة
- شاشة اختيار الحالة.
- لوحة رئيسية وملخص يومي.
- تسجيل الماء والنوم والمكملات والمزاج.
- متابعة أسبوع الحمل أو سجل الرضاعة والحفاضات.
- استبيان مزاج توعوي من 10 أسئلة وتمرين تنفس.
- جهة دعم ومشاركة ملخص نصي.
- تذكير داخل التطبيق بعد ثلاثة أيام متتالية من تسجيل مزاج منخفض أو نوم قليل.

## تنبيهات مهمة
- هذا نموذج أولي تعليمي وليس جهازاً طبياً أو بديلاً عن الطبيب.
- استبيان المزاج الحالي صياغة أولية غير معتمدة سريرياً، ولا يجوز اعتباره نسخة EPDS عربية موثقة أو استخدام نتيجته للتشخيص. يلزم استبداله بنسخة عربية معتمدة ومراجعة آلية احتساب النتيجة من مختص قبل الاستخدام الحقيقي.
- التنبيهات تُفحص عند فتح التطبيق واستخدامه؛ لا يوجد ضمان لإشعار تلقائي في الخلفية عند إغلاق المتصفح.
- لا توجد حالياً أرقام خطوط دعم عامة مضافة. يمكن للأم إضافة جهة اتصال موثوقة بنفسها.
- رقم الطوارئ الموحد في الأردن: 911.

## الملفات
- `index.html`: الهيكل والشاشات.
- `styles.css`: التصميم المتجاوب.
- `app.js`: التنقل والمنطق وحفظ البيانات محلياً.
- `manifest.json` و`sw.js`: أساسيات التثبيت والعمل دون اتصال.
